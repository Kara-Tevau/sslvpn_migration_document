# 營運管理平台

Base：`http://192.168.13.231:80`

活動、積分、公告、值班、工單、內容與排程。卡片資金處置請走 TevauPay 管理後台與財務系統。

## 鑑權

帳密換隨機 token。可疊 TOTP。角色決定看得見的選單；工單另有分派範圍。JSON Body：`username`、`password`。後續：

```http
Authorization: <token>
```

## 涵蓋

- 工作階段與首頁：登入、退出、目前登入者、待辦與未關工單
- 活動與券：活動、期數、榜單、活動充值、黑名單、節慶匯入、發獎、代金券、折扣碼
- 積分與返佣：看板、兌換、高級盒、防刷、積分碼、金額區間、獎品檔位、餘額與明細、返佣配置與日報
- 公告、值班、工單、稽核
- 郵件模板、批量推送、內容、橫幅、探索頁、功能入口、任務、商城、理財、排程、營運日報
