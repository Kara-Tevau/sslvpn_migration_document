# 財務管理系統

Base：`http://192.168.13.166:80`

帳單、對帳、台帳、費率與法幣。僅財務與獲授權營運帳號。匯出含敏感欄位，不要存到個人雲端。

列表多為 POST 分頁，匯出為 GET。對客服話術不要展開發行行名稱。

## 鑑權

與管理後台相同風格：帳密換隨機 token，Redis 存對應，**不是 JWT**。JSON Body：`username`、`password`。後續：

```http
Authorization: <token>
```

部門資料範圍生效：未授權部門的帳戶與帳單不會出現在分頁結果。

## 涵蓋

- 工作階段：登入、退出、目前登入者
- 帳單與卡帳戶：客戶與平台錢包變動、充值與提現、Modulr／ClearBank／LHV 帳戶與卡帳單、開卡銷卡、在途資金
- 資金、歸集、線下：歸集、提幣、多簽、卡銷售、渠道方、手續費與使用者帳戶、鏈上地址、卡帳戶、線下紀錄、調帳、法幣銀行、白名單、收入支出、日彙總、平台資金、其他帳戶、每日快照、發行行帳戶
- 費率、匯率、法幣：交易與渠道手續費、月費、匯率、法幣充值提現兌換、補單、退款、RFI、限額
